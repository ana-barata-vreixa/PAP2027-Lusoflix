## Descrição
O projeto é uma plataforma de streaming chamada Lusoflix, desenvolvida para permitir aos utilizadores navegar e consultar um catálogo de filmes e séries. A aplicação permite pesquisar conteúdos, visualizar informações sobre cada filme ou série, consultar o género, a classificação etária, a avaliação e a respetiva descrição. O utilizador pode também adicionar filmes e séries à Minha Lista para assistir mais tarde, utilizando o Local Storage do navegador para guardar os conteúdos. O projeto utiliza HTML, CSS, JavaScript e Bootstrap, com o objetivo de proporcionar uma experiência simples, intuitiva e responsiva em computadores, tablets e telemóveis.

## Objetivos

- Desenvolver uma plataforma de streaming com um design moderno e intuitivo.

-Criar um catálogo organizado de filmes e séries.

-Implementar um sistema de pesquisa de conteúdos.

-Permitir adicionar e remover conteúdos da Minha Lista.

-Apresentar informações detalhadas sobre filmes e séries.

-Implementar a reprodução de vídeos.

-Criar um perfil de utilizador.

-Desenvolver um painel de administração.

-Implementar avaliações e filtros por género e classificação etária.

-Garantir a adaptação da aplicação a diferentes dispositivos.
